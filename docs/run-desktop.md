# Запуск UI как desktop-приложения

Из корня проекта выполните:

```bash
cargo run --release
```

Без аргумента `--web` приложение запускается через Tauri в desktop-режиме. Для сборки без немедленного запуска выполните `cargo build --release`; бинарный файл появится в `target/release/linuxcnc-ui`.

Для разработки можно использовать `cargo run`. Если конфигурация выбирает эмулятор, запустите эмулятор отдельно.

## Веб-интерфейс из devcontainer

В терминале контейнера из корня проекта запустите сервер так:

```bash
CNC_UI_CONFIG=config/fluidnc-test.yaml cargo run -- --web
```

Сервер слушает `0.0.0.0:8080`; порт 8080 объявлен для переадресации в [`.devcontainer/devcontainer.json`](../.devcontainer/devcontainer.json). В VS Code откройте вкладку **Ports**, убедитесь, что порт `8080` имеет статус **Forwarded**, и выберите **Open in Browser**. Обычно локальный адрес будет `http://localhost:8080/`; если VS Code назначил другой адрес, используйте его из вкладки Ports.

Этот тестовый профиль подключается только к WebSocket платы `192.168.4.188:80`. Убедитесь, что хост и devcontainer могут достичь сети платы. Конфигурация по умолчанию `cnc-ui.yaml` не меняется. Веб-интерфейс содержит управляющие команды и не имеет аутентификации — оставляйте forwarded-порт доступным только в доверенном окружении и не публикуйте его в интернет.

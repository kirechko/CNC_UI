# Статус разработки адаптеров

- **GRBL по RS232:** реализован; тесты адаптера входят в успешно пройденный `cargo test --workspace`.
- **FluidNC по RS232:** подключён как вариант GRBL-адаптера, то есть использует тот же текстовый протокол.
- **FluidNC по WebSocket:** реализован с разбором текстовых и бинарных кадров, GRBL-ответов и статусов до пяти осей; проект компилируется.

**Текущий этап — проверка на реальном оборудовании.** Переданный вывод подтверждает успешную сборку и прохождение тестов, но ещё не подтверждает работу адаптеров с физическим контроллером. Для WebSocket отдельно нужны интеграционные тесты обмена кадрами; для RS232 — проверка реального порта и параметров подключения.

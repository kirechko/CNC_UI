# Проверка UI с асинхронным `cnc_core`

Мосты UI подключены к асинхронному ядру через `CNCController`: Tauri Commands и Axum Routes отправляют команды в очередь, а worker вызывает async-методы адаптера через Tokio runtime. Веб-интерфейс продолжает использовать те же команды и HTTP-маршруты.

Для текущей версии успешно прошли `cargo check --workspace` и `cargo test --workspace`. Это подтверждает сборку и автоматические тесты, но не полную работу интерфейса в реальном сценарии.

Ручная сквозная проверка UI, о которой сообщалось ранее, была проведена до перехода на async API. Поэтому утверждать, что текущая версия уже полностью проверена через Tauri и `--web`, пока нельзя. Следующий шаг — повторить такую проверку на текущем HEAD, включая статус, программу, Jog, координатные системы и шпиндель.

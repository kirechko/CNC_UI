## Tauri: текущее состояние и следующий шаг

Сейчас приложение **не использует Tauri**: нативный интерфейс написан на GTK4, а `--web` запускает Axum со статической HTML-заглушкой. Поэтому запускать проект как Tauri-приложение пока нельзя.

По п. 1.2 целевая схема такая:

- без аргументов — нативное окно Tauri v2;
- с `--web` — Axum-сервер;
- один общий UI и общее CNC-ядро для обоих режимов.

Tauri не является оболочкой для существующего GTK-интерфейса. Для целевой схемы UI нужно перенести с GTK на веб-фронтенд — согласно плану, Leptos/WASM — и подключить его к Tauri в Native-режиме и к Axum в Web-режиме. CNC-логику при этом следует вынести из GTK-зависимого запуска в общий Rust-модуль.

Предлагаемый порядок: сначала определить структуру общего ядра и веб-интерфейса, затем добавить Tauri v2 и настроить его как режим запуска по умолчанию. Не стоит просто добавлять Tauri поверх текущего GTK UI: это сохранит два разных интерфейса и не выполнит требование единого UI.

# Разделение фронтенда: что осталось

Работа не завершена. Уже вынесены API, парсеры G-code и моделей, журнал, календарь, управление программой и шпинделем, консоль команд, камера, проекция и несколько частей Jog/рендеринга. Основная логика 3D-сцены и Jog всё ещё остаётся в `web/index.html`; там же находится встроенный CSS. Разметку можно оставить в HTML, а CSS при желании вынести отдельно.

Также при переносе отрисовки заготовки `rotateStockPoint()` осталась используемой в `web/index.html`, но не определена там. Ниже исправление: экспортировать эту функцию из `stock-renderer.js` и импортировать её.

После этого стоит проверить запуск UI в браузере и Tauri: успешная компиляция Rust не проверяет загрузку и выполнение ES-модулей.

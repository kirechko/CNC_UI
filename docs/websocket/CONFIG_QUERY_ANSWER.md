Да. У FluidNC есть GRBL-совместимый запрос `$$`: он выводит активные настройки контроллера. Также полезны `$I` (информация о прошивке) и `$G` (текущее модальное состояние).

Но `$$` — это не гарантированный снимок всей конфигурации станка. Он показывает доступные контроллеру настройки, а не обязательно исходный YAML и все параметры осей. Для определения осей можно использовать список координат из `MPos`/`WPos`; количество элементов говорит, сколько осей сейчас сообщает контроллер. Ходы, единицы и прочие ограничения можно извлекать из настроек только если конкретная версия FluidNC действительно их публикует.

Сейчас WebSocket-адаптер ожидает от каждой команды строки до `ok`, но отбрасывает промежуточные ответы. Поэтому запрос `$$` можно отправить вручную через консоль, однако для показа результата в UI или автоматического формирования `MachineConfiguration` понадобится доработать сбор текстовых строк ответа в адаптере.

# CNC UI — 用户指南

CNC UI 是一个 CNC 机床控制面板，提供两个可互换的前端：桌面应用（Tauri）和内置
Web 服务器向网络上任何浏览器提供的同一套界面。它通过局域网与 FluidNC 控制器
通信，通过串口 COM 端口与 GRBL 1.1 板通信，并自带完整的软件模拟器，让你无需
硬件即可安全地熟悉界面。

> **安全第一。** 本应用不是安全控制器。在驱动真实机床之前，请在空运行环境中
> 独立验证接线、限位开关、进给速度和程序本身。串口命令不是急停——请始终能够
> 触及机床的硬件 E-stop。

## 1. 起步

### 1.1 桌面应用

先启动模拟器（除非你连接真实硬件）：

```bash
cargo run --bin cnc-emulator          # 读取 config/emulator.yaml
cargo run --bin linuxcnc-ui           # 桌面窗口
```

桌面应用通过本地套接字自动连接模拟器（`/tmp/linuxcnc-ui-emulator.sock`，可用
`CNC_EMULATOR_SOCKET` 覆盖）。

### 1.2 Web 界面

```bash
cargo run --bin cnc-web               # 服务于 http://0.0.0.0:8080
```

在浏览器打开 `http://<host>:8080`。配置项（环境变量）：

| 变量 | 含义 | 默认值 |
|---|---|---|
| `CNC_WEB_ADDRESS` | 绑定地址:端口 | `0.0.0.0:8080` |
| `CNC_UI_AUTH_USER` + `CNC_UI_AUTH_PASSWORD` | 启用 HTTP Basic 认证 | 禁用 |
| `CNC_UI_AUTH=on` / `off` | 强制开启（随机密码记录到日志）/ 显式关闭 | 自动 |
| `CNC_UI_LOG_DB` | SQLite 数据库位置 | `~/.local/state/linuxcnc-ui/messages.sqlite3` |
| `CNC_EMULATOR_SOCKET` | 模拟器套接字路径 | `/tmp/linuxcnc-ui-emulator.sock` |

认证用一个用户名/密码保护整个 Web UI；浏览器在首个请求时弹出登录框。受信任
的实验网络可不设置凭据，共享网络请务必设置。

## 2. 选择机床

页眉的连接状态芯片打开**机床对话框**。列表始终包含：

* 本地**模拟器**（仅当模拟器进程在运行时显示）；
* 串口发现的 **GRBL** 板（`ttyUSB*`、`ttyACM*`、`ttyS*`、`COMn`）；
* 局域网发现的 **FluidNC** 控制器（WebSocket :80 和 Telnet :23 探测并以 `$I`
  身份响应确认），以及经 USB 接入的 FluidNC 板（由启动横幅识别；若横幅报告
  Wi-Fi 地址，机床以其网络身份显示）。

有多个可达接口的机床会被分组：小标题标明物理机床，其传输方式以缩进行形式
列在其下——点击你想使用的接口行。点击任意行即可实时切换后端；已加载的程序和
刀路会在新机床上重新加载。刷新按钮重跑整个扫描；结果在重启间持久保存。

GRBL 探测会翻转 DTR/RTS 并复位 Arduino 板——已连接的机床自身端口不会被重复
探测。默认波特率 115200（老板可用 `CNC_GRBL_BAUD=9600`）。

## 3. POSITION 面板

* **WPOS / MPOS** 按钮切换工件坐标与机床坐标列；按钮在任何面板宽度下都精确
  位于对应坐标列的正上方。
* **G54…G59.3** 下拉框选择当前工件坐标系。
* 每根轴一行：数值、**设零**按钮和**回零**按钮。5/6 轴机床每根已配置的轴都有
  自己的行（行高超出面板时面板可滚动）。
* **全部清零**把当前位置写为所选坐标系的工件零点；**全部回零**启动回参考点。
* 按钮下方的**遥测条**显示实时运动数据：当前进给与生效模式（`Jog`、`G0`、
  `G1`、`G2`、`G3`、`Homing`）、主轴转速，以及**冷却液指示灯**（雾 M7 / 液流
  M8 开启时点亮）。
* 点击工件坐标数值可打开对话框输入精确位置。

## 4. JOG 面板

两种操控方式（页眉按钮切换）：**圆盘**和**按键**。两种运动模式：**增量**
（按一下 = 一步）和**连续**（按住 = 持续移动直到松开/停止）。

### 4.1 圆盘

圆形圆盘覆盖八个方向；圆环编码四档步距。点击扇区走一步，或连续模式下按住并
扫动。当机床报告旋转轴时，**A/B/C** 作为 Z 右侧的列出现；其表头显示单位
（角度轴 `°`，直线轴 `mm`）。步进按钮携带固定距离；Z 与旋转列共享增量/连续
切换。

### 4.2 按键

X/Y/Z 按钮带对角方向、Z±，配置了旋转轴时还有 A±、B±、C± 列，以及每个旋转轴
的步距下拉框（与圆盘显示的轴一致）。

### 4.3 进给速度

圆盘与主轴区之间是**按轴进给行**：XY、Z 和每个旋转轴各有自己的点动速度。按钮
打开预设列表（按主轴预设同样的算法由轴最大速度生成），并带一个**编辑**输入行
以输入任意值。数值保存在本地并下发控制器；旧对话框按钮（滑块图标）仍可编辑
XY/Z 及共享的旋转速度。

方形**停止**按钮（圆盘中心和按键区）取消所有点动运动。

## 5. 主轴

RPM 滑条、预设按钮（配置的最小/最大之间六个等距值，外加手动输入）、正转/反转
启动按钮。点击当前活动方向即停主轴。面板镜像遥测中的指令与实际转速。

## 6. 程序与 3D 查看器

* 从 Files 面板或查看器工具栏**加载** G-code 文件；程序经过校验、发送到控制器
  并绘制为刀路。
* 查看器图例解释线条颜色：灰色虚线 = 快移 G0，实线 = 进给 G1，圆弧 = G2/G3。
  程序运行中已走过的部分会变暗（进度由后端报告——GRBL、FluidNC 和模拟器都在
  工件坐标系帧中计算）。
* **启动 / 暂停 / 继续 / 中止**镜像控制器状态；页脚显示当前行、剩余时间估算
  和最新消息。
* **编辑器**对话框（铅笔按钮）就地编辑已加载程序，保存后重新加载；方位立方
  选择标准视图，拖动/缩放平移场景，投影开关切换透视/正交。
* **毛坯**加载 STL/OBJ 网格作为工件上下文。

## 7. FILES 面板

三个来源（连接 FluidNC 时）：**主机文件**（限制在 `CNC_UI_FILES_ROOT` 内）、
**控制器闪存**和 **SD 卡**。面板显示所查看文件系统的空闲/已用空间、列表中
文件大小；当 SD 卡缺失或未挂载时，在原文件列表位置显示其状态。浏览、上传/
下载、建目录/重命名/移动/复制/删除对三个来源行为一致。

## 8. MACROS 面板

创建、编辑、删除带每控制器调用元数据的命名 G-code 宏（如 LinuxCNC 类后端的
`M650`、FluidNC 的命名事件）。数据库**预置了 Rosetta 示例宏**，首次启动面板
即非空：

| 宏 | 用途 |
|---|---|
| 孔阵列 | 参数化生成式矩形孔阵 |
| Z 零点（简单探针） | 用 `G38.2` + `G10 L20` 探测设定工件零点 |
| 3D 探针对齐（毛坯） | 测毛坯角/边并刀路对齐（Transform 旋转+平移） |
| 烘焙 G41/G42/G40（GRBL） | 刀补烘焙启动器（Transform phase D） |
| 深孔钻（简单移动） | grbl/fluidnc 的 G83/G73 替换目标 |

这些示例的规范来源是 `config/macros/` 下的 Macro-IR YAML 文件；替换预设存放于
`config/rosetta.yaml` 和 `rosetta_settings` 表（grbl 与 fluidnc 的 G83/G73 →
深孔钻宏）。通过 Rosetta 引擎执行宏已在计划中；当前面板管理定义与元数据。

## 9. 消息日志

页脚行显示最新的报警/消息；面板（列表图标）打开完整历史，可按级别/来源过滤、
日期范围日历、搜索、排序与分页，并可"复制可见" / "另存为文本"。条目在 SQLite
数据库中跨重启保存。

## 10. 设置

齿轮按钮打开界面设置：**主题**（暗色、亮色、绿色、灰色）和**语言**（English、
Русский、中文、فارسی）。布局选择——列高和面板高——按浏览器记忆。

## 11. 键盘与无障碍

JOG 面板获得焦点时：方向键控制 X/Y，PageUp/PageDown 控制 Z，按住 `Ctrl` 进入
连续模式；每个控件都带当前语言的样式化提示和无障碍标签。

## 12. 故障排查

* 浏览 FluidNC 文件时报 **"GET response: missing header terminator"** ——
  当前版本已修复（解析器现在接受 LF-only 的 HTTP 响应）；若仍出现请升级应用。
* **机床未被发现** —— 确认控制器在同一 /24 网段，或多次点击刷新手动添加；
  仅有 Telnet 的设备在 `$ESP120` 之后经 WebSocket 确认。
* **GRBL 运行时刀路不高亮** —— 检查工作偏置：进度在激活工件坐标系帧中计算。
* **Web UI 要求登录** —— 有人以 `CNC_UI_AUTH*` 变量启动了 `cnc-web`；取消这些
  变量（或 `CNC_UI_AUTH=off`）即可开放使用。

完整 API 与架构细节：项目 README 与 `docs/`。

# Статус разделения фронтенда

Работа ещё не завершена: в `web/index.html` вынесены только API-вызовы (`web/js/api.js`) и разбор G-code (`web/js/gcode.js`). Основная логика интерфейса и стили по-прежнему находятся внутри HTML.

Дальше можно постепенно выделить ES-модули для 3D-просмотра и заготовок, журнала и календаря, Jog, управления шпинделем и редактора команд/G-code. После каждого этапа стоит запускать `cargo test --workspace` и проверять интерфейс в браузере и Tauri. Переписывать приложение на Vue, React или Svelte для этого не требуется.

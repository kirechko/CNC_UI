# Статус разделения фронтенда

Работа ещё не завершена: в ES-модули уже вынесены API-вызовы (`web/js/api.js`), разбор G-code (`web/js/gcode.js`), OBJ/STL/Three.js JSON (`web/js/obj.js`, `web/js/stock.js`) и переключение вкладок боковой панели (`web/js/sidebar.js`). Основная логика журнала, Jog, управления шпинделем и 3D-рендеринга, а также стили по-прежнему находятся в `web/index.html`.

Следующими разумно вынести журнал с календарём и затем управление Jog. После каждого этапа стоит запускать `cargo test --workspace` и проверять интерфейс в браузере и Tauri. Переписывать приложение на Vue, React или Svelte для этого не требуется.

Profiles and tools: guidance

Profiles and tools are local user-authored records used for preflight and operator reference only.

  • Leave unknown travel or speed fields blank; unknown is not a safety limit.
  • The active profile is persisted for preflight. Selecting it does not identify a physical machine or configure controller settings.
  • Tool references link records by local id; no tool-change or spindle command is sent.
  • JSON import/export preserves metadata. Photo references are text only; geometry/model upload is not part of this feature.
